Why it feels different

Community momentum, without the hustle.

Small, specific encouragement. Local AI. No engagement metrics that reward volume over kindness.

Local AI, zero API bills

Ollama runs on your hardware. No Gemini key, no per-message invoice, no chat content sent to an AI vendor.

Six ways to join

Discord, Slack, Telegram, Matrix, a signed HTTP bridge and a CLI. Same brain, same database, same community.

Truly trilingual

English, 中文 and 日本語 across the interface, command aliases and docs. Language is remembered per member.

Fair, idempotent points

Points follow the GitHub identity. A unique activity ledger means webhooks, polling and manual refreshes never double-count.

Built for operations

Health and readiness endpoints, Prometheus metrics, JSON logs, migrations, Docker, backups and a real runbook.

Kind by default

Privacy controls, DM-only deletion, opt-out, admin allowlists and tone reflection that never diagnoses a person.

One bot, many rooms

Meet people where they already talk.

No public URL is needed for Discord, Slack or Telegram. The bridge covers everything else.

Discord

Gateway

Slash commands, prefix commands, DMs and mentions. Message Content Intent only for text commands.

Slack

Socket Mode

Mentions and DMs over an outbound WebSocket. No request URL or public ingress.

Telegram

Long polling

Localized command menus, group mentions and persistent update offsets. No webhook required.

Matrix

/sync

Unencrypted community rooms, mention detection and chunked replies. E2EE is deliberately out of scope.

Any other chat app

HTTP + HMAC

Feishu, WeCom, LINE, Teams, Zulip, a web widget, n8n: POST a signed JSON message and receive the replies.

Five-minute start

Run it on your laptop tonight.

Python 3.11+ and Ollama are the only things you need. The CLI demo creates a local SQLite database and needs no Discord or GitHub token.

Full quickstart ↗ Documentation ↗
terminal
# 1. local model
ollama pull qwen2.5:3b

# 2. install
git clone https://github.com/cxy2696/GitHub-Community-Bot.git
cd GitHub-Community-Bot
python -m venv .venv && source .venv/bin/activate
pip install -e .
cp .env.example .env

# 3. try it, no platform tokens
HTTP_ENABLED=false python -m github_community_bot --cli
